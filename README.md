# ECHORA

Static brand site for ECHORA (kurtis, kurti sets, dresses, gifting). No build step.

- Contact / WhatsApp number: +91 91874 64146 (set in `script.js` as `PHONE`, and in static hrefs in `index.html`)
- Products: edit `PRODUCTS` in `script.js`. Add `img: 'assets/products/<file>.webp'` to replace placeholder art with a photo.
- Brand colours: Deep Burgundy `#510007`, Champagne `#E8D5BC`.
- Local: `python3 -m http.server 4173`
